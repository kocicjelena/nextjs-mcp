# Template 07 — `public/sw.js`

Plain JavaScript. Place in `public/sw.js` — Next.js serves `public/` at the root.
Requires `Service-Worker-Allowed: /` header in `next.config.ts` (see SKILL.md).

---

```javascript
// public/sw.js
// Service Worker for the WebMCP Agentic Showcase.
//
// install  → use addRoutes() to bypass SW for /api/* when not running
// activate → claim all clients immediately  
// fetch    → pass-through to network (extend here for caching strategies)

self.addEventListener("install", (event) => {
  // ServiceWorkerGlobalScope.addRoutes — Chrome 116+
  // Routes /api/* directly to network when the SW is dormant,
  // preventing a startup delay on the critical agent + tool API calls.
  if ("addRoutes" in event) {
    event.addRoutes({
      condition: {
        urlPattern: "/api/*",
        runningStatus: "not-running",
      },
      source: "network",
    });
  }

  // Skip waiting so the new SW activates immediately
  self.skipWaiting();
});

self.addEventListener("activate", (event) => {
  // Claim all open clients so the SW is active without a page reload
  event.waitUntil(self.clients.claim());
});

self.addEventListener("fetch", (event) => {
  // Default: pass everything through to network.
  // Add caching strategies here as the app grows.
  event.respondWith(fetch(event.request));
});

// ─── WebMCP model-context extension point ────────────────────────────────────
// When the browser ships WorkerNavigator.serviceWorker + modelContext,
// tool registration from the SW will look like:
//
//   navigator.serviceWorker.ready.then(reg => {
//     reg.active.postMessage({ type: 'REGISTER_TOOLS', tools: [...] });
//   });
//
// For now, registration happens in the main thread via useNavigatorWorker.
// This comment is a placeholder for that future extension.
```
